Para cada línea del archivo CSV se debe crear un archivo XML en una subcarpeta del proyecto llamada "xml".

El nombre del archivo debe ser el del país (campo "country") seguido de la extensión .xml (por ejemplo, "Zimbabwe.xml").

Para crear los archivos XML debes utilizar las funciones de Java vistas durante el curso. 

Además, aparte de crear los archivos en la subcarpeta "xml", debes mostrar el contenido concatenado de todos los archivos XML en un componente de tipo JTextArea (o similar) de la aplicación.
