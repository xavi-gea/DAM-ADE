La aplicación debe permitir introducir una consulta de tipo SELECT libre, para que un usuario pueda realizar las búsquedas que le interesen. Debes tener en cuenta que un usuario de tipo “client” solo podrá realizar consultas sobre la tabla “population”, mientras que el usuario “admin” puede consultar cualquier tabla de la base de datos (aunque en este caso solo haya dos: “users” y “population”). De esta forma, se puede controlar fácilmente a qué datos puede acceder cada usuario.

Una vez realizada la consulta SELECT, debes mostrar lo que devuelve en un componente de la interfaz gráfica.

Puedes investigar diferentes componentes además del típico JTextArea para que la información se muestre de una manera más amigable.
